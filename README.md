### Project Description
CHAKKA-X is an unnecessarily advanced simulation and investigation system built around one very important question:
ചക്ക വീണു, മുയൽ ചത്തു. എങ്ങനെ?
The project lets users recreate the incident by changing tree height, jackfruit weight, wind, rabbit position, reaction time and other parameters, then simulates the event and performs a root-cause investigation.

### The Problem (that doesn't exist)
A jackfruit may fall from a tree and, under extremely unfortunate circumstances, encounter a rabbit.But how do we know **why the jackfruit fell, whether it actually hit the rabbit, whether the rabbit could have escaped, and what caused the whole incident? Nobody knows.So naturally, we built an entire investigation platform.

### The Solution (that nobody asked for)
CHAKKA-X combines physics simulation, probability, animation, scenario analysis and forensic-style investigation to investigate the incident.The experience starts with a cartoon animation of the event, followed by  aninteractive simulation where users can modify the conditions. The system calculates the fall, predicts the collision and determines a simulated rabbit outcome before moving into root-cause investigation.Because one reality was obviously not enough, the project can also explore alternative scenarios and simulate thousands of possible incidents.

## Technical Details
### Technologies/Components Used
For Software:
- Language: TypeScript, JavaScript
- Framework: Next.js / React
- Styling: Tailwind CSS
- Animation: Framer Motion
- Visualization: SVG / Canvas / Recharts
- State Management: Zustand
- Physics: Custom JavaScript/TypeScript simulation engine
- Simulation: Monte Carlo scenario analysis
- Deployment: Vercel
- Version Control: Git & GitHub
- Development: Antigravity
  
For Hardware:
- No physical hardware required
- The project is primarily a software-based simulation and interactive web experience.
